# Proyecto de Taller de Git

Este es un repositorio para el taller de Git.

## Pasos para subir a GitHub

1. Crea un repositorio en GitHub llamado `proyecto-taller-git`.
2. Ejecuta los siguientes comandos en tu terminal:

```bash
git add README.md
git commit -m "Primer commit: README inicial"
git branch -M main
git remote add origin https://github.com/TU_USUARIO/proyecto-taller-git.git
git push -u origin main
```
